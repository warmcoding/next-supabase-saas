# v0.1.0 — Setup Panel Skeleton

**Released**: 2026-09-23

## Why this project exists

I built two SaaS products with this stack (Next.js + Supabase + Cloudflare R2 + Modal). Both times, the hardest part wasn't the business logic — it was the setup.

Keys are scattered across five different dashboards. Supabase's service_role key, R2's secret (shown only once), Modal's token, OAuth callback URLs... every new project meant hours of hunting, guessing, and debugging config.

So I'm building the starter I wish I had: one setup panel, one flow, less friction. The goal is simple — **let the next person go from clone to running app in 30 minutes, not a full day.**

## ✨ Added

- Setup panel at `/setup` with four tabs: Environment, Database, CLI, Guide
- Environment variable form that writes to `.env.local` via Server Actions
- Live status detection for each required key (✅ configured / ❌ missing)
- Guide page with step-by-step instructions for Supabase, Cloudflare R2, and Modal
- CLI page skeleton with the common Supabase commands

## 🔧 Fixed

- `searchParams` not awaited (Next 15 async API)
- `app/setup/layout.tsx` silently ignored due to a trailing space in the filename
